# Backlog por Fases

## Fase 0 - Fundacion

- Crear arquitectura Docker Compose.
- Crear API FastAPI multi-tenant.
- Crear esquema PostgreSQL.
- Crear Schedule Intake como entrada obligatoria XML/XER.
- Crear dashboard React inicial.
- Crear datos semilla de proyecto de control integrado.

## Fase 1 - Control Core MVP

- Importar cronogramas XML/XER en staging.
- Validar data quality del cronograma antes de activar control.
- CRUD de proyectos, WBS, actividades y cuentas de control.
- Captura de progreso y costos reales.
- Calculo EVM.
- Early warnings SPI/CPI/productividad.
- Dashboard ejecutivo y operacional.

## Fase 2 - Cambios, contratos y documentos

- Integrar AWP: CWA/CWP/EWP/PWP/IWP, path of construction, constraint log y readiness.
- Workflow de cambios.
- Contratos y comunicaciones.
- Documentos vinculados a cuentas, eventos, cambios y claims.
- Auditoria completa.

## Fase 3 - Claims / Forensic

- Registro de eventos reclamables.
- Analisis de causalidad.
- Impacto en plazo/costo.
- Matriz de entitlement RP120R-21 para cambios, ordenes de cambio y claims.
- Matriz de cumulative impact RP130R-23 para productividad, measured mile, cambios acumulados y danos.
- Paquetes de evidencia.
- Reportes forenses.

## Fase 4 - IA empresarial

- Explicacion de desviaciones.
- Deteccion de riesgo contextual.
- Generacion de reportes narrativos.
- Analisis asistido de reclamos.
- Resumen contractual y matriz de obligaciones.

## Fase 5 - Integraciones

- Integracion bidireccional con herramientas de programacion.
- ERP / contabilidad.
- EDMS / SharePoint.
- IoT, campo y mobile offline.
- BI externo.
